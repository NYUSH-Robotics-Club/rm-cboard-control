# yaw / pitch 实时监控

电脑经 ST-Link/SWD 读取云台控制回调结束时发布的快照，默认每秒刷新20次，自动保存CSV。
固件不在回调中打印，不需要新增串口线。当前实现保持裸机、现有PID和电调模式。

## 启动

首次使用须构建并烧录含监控快照的新固件，然后保持ST-Link连接：

```sh
source tools/activate.sh
just build
just flash
just monitor
```

`just flash`使用已有烧录流程和本机的复位运行设置。**监控命令自身不会烧录、暂停、
复位、恢复CPU运行、解锁输出或驱动电机。** 初次连接先读取Flash并在电脑端与ELF生成的
二进制逐字节比较；不匹配就退出，请烧录所选构建后重新启动。不能用历史ELF地址读取新固件。

按Ctrl+C退出并保留记录。CSV默认保存在`build/monitor/gimbal-日期-时间.csv`，
同名JSON记录ELF摘要/探针/镜像匹配结果，`.openocd.log`用于连接故障排查。
监控与构建/烧录共用操作锁；烧录前先退出监控，也应关闭占用同一探针的调试器。

可选用法：

```sh
just monitor 50
python3 tools/gimbal_monitor.py --hz 30 --duration 60 --csv build/monitor/test-01.csv
python3 tools/gimbal_monitor.py --elf /完整路径/NYUSH_Infantry.elf --serial 探针序列号
python3 tools/gimbal_monitor.py --prepare-only
```

采样率范围1～100Hz，实际值受SWD读取和电脑终端速度限制；界面显示实测速率。
`--prepare-only`只检查本地ELF和布局，不连接硬件。默认使用`.firmware.local.json`选择的
车型/构建和OpenOCD，程序仅依赖Python标准库及已有Arm工具链。
若Linux提示USB权限不足，查看同名OpenOCD日志，并按现有开发环境说明处理探针访问权限。

## 数值含义

| 项目 | 实际值 | 目标值 |
|---|---|---|
| 电流 | 电调反馈的有符号原始刻度 | 包含前馈/重力、应用限幅后的电流模式服务请求 |
| 位置 | yaw连续编码位置；pitch单圈绝对编码 | 同一坐标下的位置目标，8192刻度为一圈 |
| 速度 | 电机原始RPM | 本次速度内环采用的目标RPM |

**步兵pitch目前为电压控制，没有可读取的目标电流。** 界面显示`N/A`，另列电压命令
原始刻度。yaw当前为电流控制，因此有目标电流刻度。程序通过电机服务查询命令单位，
未知模式不推断电流；数值不直接标为A或V，也不修改电调模式以补造目标电流。

命令值是应用提交给电机服务的请求，不是仅取`PID.output`，也不是从CAN邮箱读出的已发送帧。
`command_status=0`表示服务接受请求，不证明CAN发送完成或电调已经执行；负数表示失败，
此时目标电流显示`N/A`。例如`-4`为不支持/配置初始化失败，`-3`为未就绪，`-5`为模式不匹配。

yaw启用`speed_loop_only`时，位置目标只是备忘值，界面标出“未闭合位置环”；回中目标
为0RPM不代表锁位置或零电流。停机时速度目标显示`N/A`，CSV中的0占位必须结合flags解释，
避免使用`PID_Reset`留下的旧目标。完整spin模式的内环可能使用IMU世界角速度；此时另行显示
内环实际反馈，电机相对RPM与该目标不能直接当作同一坐标比较。

界面还显示使能、启动对齐、控制回调计数/间隔、反馈年龄、快照年龄、服务状态及未采回调数。
反馈未出现或超过100ms时提示过期；快照超过100ms，或电脑观察回调计数停止超过100ms时，
标为历史值。yaw控制内部另有20ms连续性检查，不能仅凭100ms反馈标志判断控制有效。

## 数据一致性与范围

`application/gimbal/gimbal_monitor.h`定义v1布局，`g_gimbal_monitor`可直接在调试器中展开查看。
云台消息派发上下文独占发布；序号变成奇数后写入，完成后变回偶数。电脑读取整块及末尾序号，
只有前后相同的偶数才接受；结构版本/长度错误立即退出。双轴反馈本来就来自各自的CAN时刻，
快照一致不表示两台电机在同一微秒采样，`feedback_ms`保留各自的反馈时间。

这是**控制回调最新快照监控**，不是1kHz逐帧CAN录制。电脑两次采样间可能经过多个回调，
`未采回调`统计跳过的回调数，不是总线丢帧数。需要逐帧分析CAN时应另用总线采集工具。
监控不会更改冻结底层；实际回调耗时增量和SWD读取对实机时序的影响仍需上板测量。
