# 步兵云台方向平移跟随

左拨杆中档时，左摇杆平移以云台朝向为参考；上档小陀螺与下档普通模式
采用各自的路由逻辑。当前行为以 `application/cmd/command_router.c` 为准。

## 标定

`config/robots/infantry_standard.c` 当前设置
`yaw_forward_ticks=4890`、`yaw_ccw_sign=-1`。4890 是用户记录的
云台朝底盘正前方编码；符号仍需在相同固件的实车上核对。
这两个量是相对底盘的安装标定，不是世界航向或电机电流方向。

路由取 yaw 电机的新鲜编码反馈，按前向零点换算云台相对车体角，
再把云台坐标下的平移输入转为车体坐标。反馈过期或角度无效时，
跟随平移应停机，不能沿用旧角度继续驱动。

## 验证

架空底盘，在云台正前方、左/右约 90° 和跨 8191→0 时逐一检查
前后、左右单轴输入与四轮目标方向。主机测试覆盖数学路径；
构建和旧日志不能证明当前机械安装符号已正确。
