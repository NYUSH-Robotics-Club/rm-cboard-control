# 诊断分支边界

- 目标为 STM32F407 RoboMaster C 板，经典 CAN 2.0、最大 1 Mbps；不支持 CAN FD。
- 当前只构建独立诊断固件，入口 `runtime/diagnosis/main.c`。原整车任务、配置和
  上层实现已删除；冻结底层原样保留，旧入口不参与构建。
- 依赖方向 `runtime -> services/core -> bsp -> HAL`。原始 CAN 是此工具的显式接口。
- 上电只听，无自动电机命令。所有测试发送都是单次请求，不自动扫描、恢复或重发。
- 达妙 ID、控制模式、映射范围和实机接线须确认；不能把网页的探测起点当作实机配置。
  不为其他型号借用 J3507 的限位、力矩、控制增益或几何参数。
- SWD 观察到回调/发送成功不等于电机执行成功，回环不验证外部物理总线。
- 编译与主机模拟不能证明实机时序、电气连接或运动表现。烧录与驱动电机不作为自动测试。
- 待实机验证：ST-Link 运行中 SRAM 读写时延、两路 CAN 正常/只听/回环、实际 J3507
  固件的参数回复、满载丢帧、缺 ACK/Bus-off/取消路径和供电/终端配置。

验证入口为 `sh tests/host/run_tests.sh`，以及 Debug 和 Release CMake presets。
不要向此页追加任务流水账。
