# GM6020 模式与当前配置

现行配置见 `config/robots/infantry_standard.c`。电调保存的内部模式
不会被本仓库自动读取或切换；软件协议与实物电调模式必须匹配。

| 轴 | CAN / 硬件 ID | 反馈 ID | 控制帧 / 槽位 | 当前软件协议 |
|---|---|---|---|---|
| yaw | CAN1 / 5 | 0x209 | 0x2FE / 0 | 电流原始刻度 |
| pitch | CAN2 / 4 | 0x208 | 0x1FF / 3 | 电压原始刻度 |

yaw 配置的协议命令限幅为 12000 原始刻度，速度 PID 和前馈还受各自
限幅约束；这些刻度不能直接当作安培。pitch 使用 1607～2374
绝对编码目标限位，启动目标和重力零点为 1971，重力补偿当前为 0。
目标限位不保证机构不会因惯性越界。

配置中的 `speed_loop_only=false` 表示 yaw 源码选择位置与速度串级
闭环；是否运行在板上需核对匹配的固件和遥测。历史 PID 参数、旧
Flash 哈希和一次性调参建议不属于现行协议说明，可在 Git 历史查阅。

首次核对新电调或模式时，先确认官方协议和电调设置，再从零指令、
反馈方向和低速短时动作逐步验证。不能把电压/电流模式的 PID 参数互抄。
厂商原始资料保存在 `docs/official-docs/`。

普通/视觉/小陀螺 yaw 共用电机配置的同一套位置与速度PID，在位置环输出后扣除 `gain * actual_rpm`，再执行原有分段
速度限幅及反向制动限幅。`near_damping_blend_deg` 是近端角度边界两侧的
平滑过渡半宽，使用 smoothstep 在 near 与 approach 阻尼间插值；0 保留
原硬切换。远/中段边界及各段速度上限不参与这次平滑。

`near_brake_release_rpm` 与 `near_brake_full_rpm` 控制高速近端制动保持：
在中/近区向目标运动且速度超过 release 时建立保持，以实际速度在两个阈值
间平滑提高阻尼，最高取 near/approach 中较大值。误差过零不解除保持；
速度降到 release、离开中/近区或实际运动反向时重评估。目标主动向原接近
方向的反方向移动也会清除旧保持，并按新目标重新判断是否仍在接近。
两速度阈值同时为0关闭保持；否则须满足 `0 < release < full`。
近端过渡区不得越过零误差或远/中边界；非法配置沿用 yaw 停止并重新对齐路径。

步兵启用此功能；哨兵新增参数均为0，保留原行为。模式切换、停机、反馈
失效及速度环旁路会清除保持状态，小陀螺也使用这条阻尼路径。该逻辑不冻结
目标、不新增位置死区；低于 release 的小角度跟踪仍采用基础近端阻尼。

小陀螺不再配置独立`spin_pid_outer/inner`或`spin_speed_rpm`，共用普通遥控的
`manual_speed_rpm`、分段限速、阻尼、反向制动、积分处理和前馈。
保留世界航向目标与IMU角速度反馈（rad/s转RPM），避免将底盘相对转速当作车头世界转速。
阻尼的目标换向判断使用世界航向目标，不能使用随底盘转动的等效编码目标。
logger的PID数据统一来自电机PID，SPIN仍标记IMU速度来源。
底盘自转与行进路由、摇杆调整世界航向的倍率以及2500 ms退出制动窗口保持原逻辑。
普通模式参数用于世界坐标稳头后的实际效果仍需上板验证。

## Pitch遥控位置跟踪

`config/robots/infantry_standard.c` 的 `s_pitch_control` 通过电机8的
`pitch_control` 接入。PitchControlConfig包含摇杆输入、单一速度阻尼和可选负载前馈；电机原有的`pid_outer/pid_inner`
和电压协议保持独立。缺配置、非法参数或控制/反馈间隔超过20ms时，
停两轴并重新等待反馈对齐，不追补失联期间的输入。

手动目标增量为 `direction * clamp(stick, -1, 1) * manual_rate_deg_s *
manual_stick_gain * dt_s * 8192 / 360`，单位编码刻度。相同毫秒重复调用
不增加目标；松杆保持目标。目标始终裁剪到1607～2374，达到边界后
反向输入可以立即离开，不积累限位外目标。启动目标仍为1971。

pitch使用单一速度阻尼：`speed_target = outer_pid_output -
velocity_damping_gain * actual_rpm`，随后按原位置PID的`output_max`限幅。
不再使用near/approach/far分段限速、分段阻尼或反向制动限幅/保持。
当前阻尼系数0.60，位置PID速度输出上限仍为300RPM；该上限是控制参考，
不是实际机构速度保证。满杆目标变化率仍为1200×0.3=360°/s。

pitch位置环每次控制回调更新，PID数值不变。已移除按停止距离触发的
软制动权重、恢复计时和最终电压缩放，也不恢复此前的速度触发硬切断。
速度目标只经过单一实际RPM阻尼及原位置环输出上限；总电压只受原内环/
协议输出上限约束。积分仅在总输出饱和且继续同向增长时受限，不再因
制动权重冻结。目标裁剪、4ticks端点外推杆拒绝及下述越界锁存保留。
这些保护不能保证运动中的机构不会因惯性超过实际端点，仍需实车验证。

发生实际越界后双轴保持零输出，故障锁存直到收到禁用命令；实际回到范围内、
重新使能且反馈稳定后才允许启动，避免弹簧回弹时自动重复追向端点。
正常初始位置/目标越界检查保留。测试或恢复时不得通过放宽限位绕过此条件。

`PitchControl_Load`按实际编码计算经验负载前馈，电压指令单位：
`gain * (bias + slope_per_tick * (actual_ticks-reference_ticks))`。
拟合范围外钳位到两端，不外推；`load_output_max`限制补偿，`load_gain=0`
关闭补偿。拟合脚本、原始保持点、线性/二次模型交叉验证和图表见
`analysis/pitch_20261002_235954/`。这是弹簧、摩擦和重力的合成经验模型，
不是力或转矩标定；留一交叉验证误差约1241电压指令刻度。当前`load_gain=0`，
双向摩擦/保持负载尚未验证，补偿关闭，拟合参数仅保留供后续标定。

前馈不受速度目标过零/换向影响。pitch积分不再按yaw规则清零/乘0.2，
用于修正负载残差；停机/故障仍清PID。前馈、PID和重力项之和受原内环
输出上限与协议上限共同约束，同向积分在总输出饱和时停止增长。
小陀螺下pitch也使用该路径。视觉pitch按每个新帧的弧度误差生成绝对编码目标，
再复用本路径及原有限位；帧间保持目标，详见[视觉控制](guides/vision-diagnostics.md)。
