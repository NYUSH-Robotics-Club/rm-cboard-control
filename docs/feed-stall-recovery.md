# 拨弹电机持续高电流退弹

检测接在 `ShooterController` 的拨弹角色上，当前步兵对应 CAN2 硬件 ID 3、
软件编号 9。用户称实物为 M2006，但现有车型配置仍写 `MOTOR_TYPE_M3508`；
本次只接入应用逻辑，未更改型号、CAN 地址、协议或原速度 PID，型号映射待确认。
哨兵没有发射电机，不启用该动作。

## 行为

1. 开始拨弹且三台发射电机反馈健康时，按电流反馈绝对值检测；达到阈值连续
   500 ms 后，以 −500 转子 RPM 为目标反转 200 ms。反转一次指一段限时动作，
   不代表输出轴转一圈，也不保证堵住的轴实际发生转动。
2. 反转到时，本轮拨盘零电流，下一轮从零按原斜坡恢复 +1000 RPM 拨弹。
   同一次拨弹最多反转一次；恢复后若再次连续高电流 500 ms，拨盘保持零电流，
   松开拨弹再开启才能重新尝试。一次反转成功后保持本次次数已用，低电流不补次数。
3. 取消拨弹立即取消计时、反转和锁定。任一发射电机反馈缺失/超过 100 ms，
   或 CAN 输出锁定时，沿用三台一起零命令的联锁；恢复不补发已用反转次数，
   已重堵锁定也保留到取消拨弹。摩擦轮原斜坡、零速闭环及 PID 参数保留。

换向和恢复时清拨盘 PID 历史，用当前速度初始化微分。计时用可回绕的毫秒时间，
不是回调次数。低于电流阈值的已处理反馈会打断连续计时；控制间隔超过 100 ms
也重新计时。反转到期和故障处理均在下次控制计算时执行，主循环停止时不能保证截止。

## 参数

电流阈值在 `application/shoot/shooter_controller.c` 中显式定义，可直接修改初始值：

```c
int16_t g_feed_stall_current_threshold = 800;
```

单位为反馈原始刻度，合法范围1..32767。源码修改后重新构建/烧录生效；也可包含
`shooter_controller.h`，在主循环已取消拨弹时赋值，例如
`g_feed_stall_current_threshold = 1200;`，运行时赋值不持久保存，不在中断中修改。
非正值会锁定拨盘零电流，修正参数后取消拨弹才能解锁。
其余时间和反转速度参数继续保留在 `application/shoot/shooter_controller.h`：

| 参数 | 初始值 | 含义 |
|---|---:|---|
| `g_feed_stall_current_threshold` | 800 | 可调变量；电流反馈绝对值，原始刻度，非安培 |
| `FEED_STALL_DURATION_MS` | 500 | 连续高电流时间，毫秒 |
| `FEED_REVERSE_SPEED_RPM` | 500 | 反向速度的正值幅度，转子 RPM |
| `FEED_REVERSE_DURATION_MS` | 200 | 反转目标持续时间，毫秒 |

这些值是未标定的初调参数。当前拨弹目标 1000 RPM、速度 Kp=1、Ki=Kd=0，
堵住时比例输出约 1000 原始刻度，因此先设 800 门槛；需用实际正常拨弹、启动
和卡弹电流校准，不能把它称为额定电流或已验证堵转阈值。这里只判断持续高电流，
高速重载也可能触发，不额外要求低转速。当前正常拨弹方向固定为正，反向目标取负。

主机回归覆盖阈值边界、短脉冲、正负电流/−32768、反转截止、重堵锁定、取消、
逐台失联、CAN 锁定、恢复次数保留、不规则回调、重复时间、时间回绕及直接计算入口。
构建/主机测试不能代替实物型号确认、机械退弹量和带载效果验证。
