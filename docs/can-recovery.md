# CAN 故障恢复与重新使能

`BspCan_Service()` 在主循环处理 CAN1/CAN2 的 Bus-Off 恢复；
`Src/main.c` 仍为裸机入口。故障时两路电机输出均锁定，
先取消硬件邮箱旧报文并清 DJI 软件发送缓冲，再等待总线退出故障。
超时保持停机并延迟重试；恢复不会修好供电、接线或终端电阻。

## 解锁条件

两路 CAN 健康后，仍需遥控在线、两只拨杆下位、模拟通道回中并稳定
满足控制器的确认窗口，才解除输出锁定。解锁当次不会重发故障前
的非零指令。云台还须等待新鲜反馈并重新对齐；发射机构重连后
沿用其拨杆重新使能规则。详细条件以 `bsp/can/bsp_can.c` 和
`application/cmd/cmd_controller.c` 为准。

正常下档时摩擦轮按速度斜坡减到零并保持速度闭环；CAN 锁定或
反馈失效时则清目标/PID并给零命令，两种停机行为不能混同。
零命令是软件请求，断线电机不一定收到，机械也不会瞬间停稳。

## 诊断边界

`BspCan_GetRecovery()` 可读取两路恢复阶段与故障计数；
`MsgCenter_GetDiagnostics()` 提供队列覆盖和派发上限计数。
发送提交次数不等于电调已经执行。主机测试模拟状态机与回中解锁，
不能证明真实总线电气问题已消除。每次实车诊断应保存对应的固件
身份、采样时间、CAN 状态和电机反馈；历史窗口不能代表现在。
