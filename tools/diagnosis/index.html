01 / 选择接口

上电默认只听。直接连接电机时，选择「正常 / 收发」后应用配置。回环仅验证 C 板内部，不能证明线缆和电机正常。

02 / 达妙只读探测

初始 ID 只是探测起点，并非已确认的电机配置。读取发送到 0x7FF，不使能电机；响应会出现在下方报文中。

探测逐个读取 RID 7（反馈 ID），约 2 秒。未知型号须先核对其参数协议。不会自动改写寄存器或保存参数。

03 / 单次测试报文

失能帧使用上面的命令 ID（须与电机模式匹配），不是硬件急停。测试报文只发一次；断开网页或 ST-Link 不会自动使能或失能电机。

链路状态

如何判断问题

心跳停住 → 检查固件运行和 ST-Link。
TX_ERROR / LEC=3 → 未收到 ACK，检查电机供电、H/L、终端和波特率。
TX_OK 但没有电机回复 → 至少有 CAN 节点 ACK；继续核对电机 ID、模式、回复协议。
内部回环成功 → 仅说明内部收发链路通过。
Bus-off → 排除物理连接问题后重新应用配置；固件不自动恢复或重发。
